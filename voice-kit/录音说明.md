# 人声采样录音说明

## 怎么录

1. **戴上耳机**，双击小宝乐队文件夹里的 `start.bat`，黑色窗口要一直开着。
2. 用 Chrome 或 Edge 打开 **http://127.0.0.1:4318/voice-kit/**。第一次点"录音"时，浏览器会问能不能用麦克风，选**允许**。
3. 每个音都是一样的流程：
   - 点 **⏺ 录音**，或者按空格；
   - 耳机里先放参考音，然后"嘀、嘀"两声倒数；
   - 屏幕变绿显示"唱"，就开始唱；
   - 计时条走完就停，后面多录的一点点是余量，不用管；
   - 录完自动保存，并跳到下一个音。
4. 想再听一遍参考音按 **🔊 听音**（L 键），想听刚才录的按 **▶ 回放**（P 键）。不满意就再按一次录音，新录的会覆盖旧的。
5. 唱着不舒服的音（太低发虚、太高要挤）直接按 **下一个 →** 跳过，我会用相邻的音补上。
6. 左边能看到每段录了几个，右上角是总进度。不用一口气录完，随时可以关掉，下次打开会接着从没录的地方开始。

## 每段唱什么

| 段 | 内容 | 要点 |
|---|---|---|
| 01 长音·乌 | 乌（u），E2 到 G4 共 10 个音 | 直音，**不要颤音**，音量平稳，唱 4 秒 |
| 02 长音·啊 | 啊（a），同上 | 同上 |
| 03 哼鸣·嗯 | 闭嘴哼（m），同上 | 同上 |
| 04 低音短音·dm | E2 到 A#3 共 7 个音，每个音唱 3 下 | 像"德"刚出口就闭嘴变成"嗯"，很短。屏幕闪"唱！"就唱一下 |
| 05 短音·吧 | A#2 到 G4 共 8 个音，每个音唱 3 下 | 短促的"吧"，干脆收住 |
| 06 选录·假声乌 | E4 到 C#5 共 4 个音 | 用假声，唱不上去就跳过 |
| 07 选录·Beatbox | 底鼓、军鼓、舌根军鼓、踩镲、开镲，每种 4 下 | 能发出来就行，不求专业 |

必录 01 到 05，一共 45 个音，每个音大约 8 秒，顺利的话 10 分钟左右能录完。

## 录音环境

- **耳机必须戴**，否则参考音会漏进录音。
- **安静**：关掉空调、风扇，手机静音。
- **麦克风**：离嘴一拳到两拳，全程不要改距离，也不要动麦克风音量。如果页面提示"太小声"或"削波了"，按提示调整后重录那个音。
- **Windows 的麦克风增强、降噪最好关掉**。页面已经关掉了浏览器自带的处理，但声卡驱动里的效果关不掉。

## 录完以后

录音保存在 `voice-kit/recordings/items/`，只在你的电脑上，不会随源码上传。在仓库目录运行：

```
python voice-kit/slice_voice.py
```

脚本会自动切片、测音高、修正唱偏的音、给长音做循环点、把重复的短音按波形拆开，生成 `data/user-instruments/my-voice.json`。重启 `start.bat` 后，乐器列表里就会出现"我的人声"，也可以直接让 Agent 用它编曲。

- 想要一个女声版本：`python voice-kit/derive_voice.py`（需要 `pip install pyworld`），会生成"我的人声 · 女声"。效果因人而异，高音区容易发尖。
- 想像小宝人声一样用 CC0 公开：见 `voice-kit/publish_voice.py` 开头的说明。
