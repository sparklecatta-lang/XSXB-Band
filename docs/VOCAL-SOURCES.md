## 多点采样合唱：没有找到可用的 CC0 来源

2026-10-07 检索过以下来源：

- Freesound 的 CC0 筛选；
- VCSL（没有人声）；
- Polyphone 和 musical-artifacts 上标为"公有领域"的合唱 SoundFont。

结论：

- 没有找到逐音采样、音域连续、干声、来源清楚的 CC0 合唱 "aah / ooh"。
- Freesound 上只有零散单音：音高不全，部分带混响。
- 标为公有领域的 SoundFont 作者或出处不明，下载还要登录。

所以和声垫、人声贝斯等有音高的人声，改用用户自己录音生成的个人音色（见下）。

## 个人人声（`data/user-instruments/`）

- `voice-kit/` 里有录音引导轨、提词器和切片脚本 `slice_voice.py`。
- 生成的乐器描述写在 `data/user-instruments/<id>.json`，录音切片写在 `data/samples/<id>/`。
- 服务器启动时，会把这些乐器并入音色清单，并标记 `personal: true`。这类乐器没有下载地址，永远不会自动下载、上传或随源码发布；`data/` 已被 git 忽略。
- 长音采样带 `loopStart` / `loopEnd`：切片时选在波形相似的位置，并预先做了交叉淡化，引擎播放时循环，音符多长就能持续多长。
