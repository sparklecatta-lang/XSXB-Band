# 采样盒（Sample Crate）

给嘻哈 / lo-fi 用的切片：全部来自**公有领域或 CC0** 的录音，逐条附来源页面和许可依据。
在工作室里是三件乐器：`crate-classical`、`crate-vocals`、`crate-speech`；每个切片是一个奏法，切片 ID 就是奏法 ID。

- 古典乐句写在 C4（MIDI 60），音符写多长就放多长；工程速度和切片 BPM 不同时自动时间拉伸（变速不变调），按别的音高会整体移调、速度不变。
- 讲话和人声是一次性触发：音符写多短都会完整播完；人声有明确音高的按实测音高定根音。
- 刻意没有收录：马丁·路德·金《I Have a Dream》（遗产方持有版权）；罗斯福 1933 就职演说的电台录音（录音版权存疑）；来源不明的德彪西《月光》录音。
