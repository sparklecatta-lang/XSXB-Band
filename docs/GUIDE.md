# 网页工作台操作说明

启动后访问 http://127.0.0.1:4318 。服务只监听本机，工程、歌曲库与音源缓存保存在 `data/`，程序退出后仍保留。网页每两秒检查 Agent 写入的更新；有未保存的修改时不会自动覆盖。

## 编辑音符

- 钢琴卷帘：双击空白处创建音符；拖动改变音高和位置；拖右侧边缘改变时值。选中音符后可在右栏修改音高、时值、起点、力度和奏法。
- 方向键微调选中音符，Shift + 上下移动一个八度。Delete 删除，Ctrl + D 复制，Ctrl + Z 撤销，Ctrl + Shift + Z 重做，空格播放 / 暂停。
- 鼓机：每小节 16 步，按四分音符分组。点亮或关闭某一步，会按需创建对应的鼓件音轨。

## 音轨与音色

- 每轨可以静音、独奏，调整音量、声像、混响发送和旋律尾音。支持多奏法的乐器可以设置轨道默认奏法，也可以给单个音符指定奏法。
- 分层音源按力度选取不同的真实录音，并轮流使用同一个音的多次录音。
- 吉他效果可选 Tuna 过载、AmpSim3 高增益前级或 NAM 神经网络箱头，并接入实测箱体 IR。驱动、明暗、干湿比例与输出电平可以在播放中调整。
- 工程用到的音源会自动下载；也可以在音源库里手动下载、试听，展开“来源、许可与下载链接”查看作者、许可和每个文件的原始地址。

## 歌曲库与导出

- 右上角“我的歌曲”可以打开、改名、复制、新建和删除歌曲。删除会移到 `data/songs/.trash/`。
- WAV 导出使用实际采样和效果链，遵循静音与独奏；MIDI 只保存音符、速度和基本 GM 设置，不带采样和效果；JSON 保存完整可编辑工程。

## 给 Agent 留言

“保存需求”把创作要求存在本机队列里，回到 Agent 聊天让它读取即可；“复制需求”会复制一段包含本地项目位置的说明。工作室不会自己调用任何 AI，也不会把内容提交到远程服务。
